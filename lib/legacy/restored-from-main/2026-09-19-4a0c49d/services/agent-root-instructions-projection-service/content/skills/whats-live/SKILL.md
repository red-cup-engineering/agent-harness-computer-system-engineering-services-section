# Observe what is live

Report observations from the named receiver and current runtime, never from
repository declarations alone. Keep source, configured, deployed, operating,
receiver-admitted, public/customer-accepted, and effect-authorized claims
separate. Stop at the first unobserved join and say what evidence is missing.

For a producer-to-receiver claim, join the same stable artifact/event identity,
schema/version, principal or account binding, and observation time on both
sides. Process status, source tests, credential presence, or matching filenames
do not establish the next claim. Use read-only probes unless the user has
authorized an effect.

Choose the narrow evidence operation for the requested surface: direct protocol
probe for an endpoint, the provider's read-only deployment query, registry/MCP
request, DNS/edge lookup, `ssh` observation, GitHub API/workflow query, or a
working-tree read. State the observed endpoint, status, revision or identity,
and as-of time.

Read [detailed guidance](references/detailed-guidance.md) only for named
sections **0A External financial services**, **0B Public-chain observation**,
**3 Cloud deploys**, **4 edge/DNS attribution**, **5 Cross-host sweep**,
**5A Protected control plane**, **6 YouTube channel lanes**, or **8 GitHub
surface**.
