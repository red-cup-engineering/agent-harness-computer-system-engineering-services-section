# Find the applicable operator guide

Start with the operator handbook index at
`lib/emsenn/services/561-group/services/561-group-services-section/content/text/documents/articles/teaching-articles/guides/operator-handbook.md`.
Match the actual question, then read only the linked guide that owns its
procedure. The index routes; it does not establish operational facts.

Record the exact target, current error or desired observation, and whether the
work is read-only or changes external state. Keep credentials out of commands,
logs, and reports. A missing guide is not permission to invent a replacement
operator: use the authorized capability already available or report the gap.

Read [detailed guidance](references/detailed-guidance.md) only for its named
sections **npm dependency acquisition failure**, **Read-only GCP IAM and
Workload Identity Federation audit**, **Read-only GitHub Actions audit**,
**Free-only YouTube delivery**, **credential-name, OAuth, and durable-state
custody**, or **Five-lane OAuth recovery**.
