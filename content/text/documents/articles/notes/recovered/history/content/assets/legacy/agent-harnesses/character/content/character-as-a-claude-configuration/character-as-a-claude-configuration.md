---
name: character as a claude configuration
description: The projection of a character record (identity, agency, per-agent defaults) into the per-project files Claude Code reads at session start.
---

A character-as-a-claude-configuration is the host-side image of a character record under the projection that maps `staff/characters/<name>/<name>.md::agency` into the Claude Code session-config vocabulary.
Two artifacts compose the projection:

- **`.mcp.json`** — the project-level MCP registry Claude Code reads to discover and spawn MCP servers.
  The character projection writes a single entry whose `env` carries the character ref so the 561 MCP server resolves the character's agency at server start.
- **`CLAUDE.md`** — the session prompt Claude Code reads as project instructions.
  The character projection writes a session-orientation block, the character's `description`, the resolved agency list with per-agent defaults, and the in-scope skill list with each skill's pre-parameterizations attributed from agency.

A character-as-a-claude-configuration is derived, not authoritative — the authoritative source is the character record under `staff/characters/`.
The projection is regenerated by `installing-a-character-as-a-claude-configuration`; hand-edits to the projected files are silently overwritten on the next install.

Two character-as-a-claude-configurations for different characters differ in: which `CHARACTER_NAME` (or character path) the `.mcp.json` env passes to the harness; the orientation prose in `CLAUDE.md`; the agency list and pre-parameterization defaults rendered into `CLAUDE.md`.
The structural shape — the file set, the schemas of each artifact — is invariant across characters.
