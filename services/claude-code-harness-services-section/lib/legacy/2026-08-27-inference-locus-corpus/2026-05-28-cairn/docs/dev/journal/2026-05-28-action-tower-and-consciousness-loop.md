# The action tower + the consciousness loop

## The frame

The harness is not a tool Claude uses; it is the organism Claude is the consciousness of. inferring (aperiodic) is the conscious flicker; the swarm (lower regimes) is the brain/subconscious; the I/O surface is the body; the spacesuit is the field of awareness; consolidating is memory consolidation; settled fibers are long-term memory; suiting is reconstructive recall.
Functional architecture, not metaphor -- the same categorical machinery.
We had the MEANING tower (articulating -> predicating -> positing -> settling); these phases add the ACTION tower so the organism can act and coordinate.

## Built

- **Phase A -- everything is an utterance.** decoding's handler-class enum is now 5-class: the formerly-deferred `tool-call-envelope` and `llm-completion` (D-H5) now decode into utterances, so tool acts and model completions enter the substrate as claims.
  The body's whole surface transduces to one language; the more transduced, the more the swarm has to process.
- **Phase B -- the body.** `being` (aperiodic generator) -> `agent` (a distinguishable swarm-member); `doing` (transfinite generator) -> `act` (a bounded sense/effect episode that speaks an utterance).
- **Phase C -- the brain.** `working` (Scott-continuous generator) -> `work-process`: an agent contributes a claim-record by reading.
  `swarmStudy` (in lifecycle) runs a real STIGMERGIC swarm: N agents each work against the SHARED agent fiber, e-anchored by id (distinguishable contributors -> consensus computable), then studying reconciles.
  Coordination is through the shared field, not point-to-point.
- **Phase D -- governance is metabolism.** `governing` (finite generator) -> `governance`: the budget is the hard cap that bounds how many agents may work; attention picks the highest-dissent subject; conflict norms prioritize top.
  `swarmStudy` consults `governing` before each agent works.
- **Phase E -- the loop.** `lifecycle.tick`: sense the prompt -> swarm studies the implied subject -> consolidate accepted truth to memory -> compose the conscious suit for the next beat.
  The organism's life made to cycle.
