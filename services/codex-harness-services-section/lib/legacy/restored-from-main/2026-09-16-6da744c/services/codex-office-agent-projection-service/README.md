# Codex Office Agent Projection Service

Projects one enterprise office and the skills realizing its duties into one
project-scoped Codex custom-agent TOML file. The office record is durable
source; `.codex/agents/<office-id>.toml` is disposable harness output.

This service revives the office projector formerly held only in the dated
Executive Office legacy corpus. Machine harnesses may call it, but the
provider-specific projection mechanism is owned here with the other reusable
Codex harness engineering.
