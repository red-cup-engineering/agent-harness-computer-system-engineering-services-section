The Antigravity carrier shall resolve the source contract of the admitted native Work through the same trusted repository, binding, preparation and candidate ports as the other hosted carriers. Source-free work shall use private read-only scratch. Source work shall retain its original closure and receiving shall inspect its produced result. Workspace choice grants no execution authority.

The adapter passes repositoryOf, bindGit, publishSourceCandidate and sourcePreparationOf to the shared carrier workspace implementation. Both workspace and session effect selection honor no-source. The deployment selects the repaired original shared workspace supplier without copying a dependency tree.

Receiving covers actual private scratch cleanup without a Git command, required candidate publishing before source writes, retained source preparation, refusal of unproduced receiving results, read-only install refusal, and a real source fixture with an unavailable submodule and failing install hook. No production or commerce acceptance follows from source qualification.
