Native Work capacity admission uses the original host-wide provider lease and kernel lock. The public reserveProviderTurn default remains immediate refusal. Explicit waitForCapacity=true reuses the existing bounded poll backoff until capacity is available. Non-boolean wait options refuse before touching custody. Duplicate scopes remain refused; no waiting request owns a slot or claims a Session. Process birth identities, active unit proofs, quota and lease release remain authoritative.

The agencyWorkCarrier advertises waitsForCapacity=true and requests that behavior for original execution and receiving. The native pump must serialize a selected waiting carrier and recheck current allocation, obligation and authority after lease acquisition, before started admission. Waiting never authorizes source effects or claims product acceptance.
